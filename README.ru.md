# Apple Devices

Нативное GNOME-приложение для управления устройствами Apple — iPhone,
iPad, iPod touch — по USB. Собрано на **GTK4 / libadwaita** поверх
открытого стека **libimobiledevice**.

> Управляйте медиатекой iPhone из Linux — с обложками, без перезагрузок
> и без борьбы с устройством.

## Возможности

- **Обзор устройства** — модель, версия iOS, серийный номер, заряд
  батареи и диаграмма накопителя.
- **Медиатека** — просмотр треков на устройстве с живым поиском и
  сортировкой (по названию, исполнителю, альбому, длительности).
- **Импорт с обложками** — импорт аудиофайлов вместе со встроенными
  обложками. Обложки записываются в Artwork-хранилище устройства и
  появляются в приложении «Музыка» **сразу** — без перезапуска и
  без перезагрузки.
- **Экспорт и удаление** — скопируйте треки обратно на компьютер,
  удалите их из медиатеки.
- **Безопасность прежде всего** — резервная копия базы медиатеки
  создаётся **перед каждой записью**
  (`~/.local/share/apple-devices/backups/`).
- **Горячее подключение USB** — подключение и отключение устройства
  обновляют интерфейс автоматически, кнопка «Обновить» не нужна.
- **Двуязычный интерфейс** — русский и английский, по гайдлайнам
  GNOME HIG: стиль Adwaita, символические иконки, адаптивные макеты.
- **Журнал отладки** — каждая операция логируется внизу окна.

Поддерживаемые форматы: MP3, AAC/M4A, FLAC, WAV, OGG, OPUS, AIFF.

## Как это работает

Приложение общается с устройством через сервисы, которые iOS сама
предоставляет по USB (usbmuxd → lockdownd → AFC). Файлы размещаются в
`/iTunes_Control`, а база медиатеки устройства
(`MediaLibrary.sqlitedb`) обновляется так, что треки и обложки выглядят
как будто всегда там были — тот же подход, что используют известные
сторонние инструменты. Закрытый протокол Apple MobileSync **не**
используется; ничего не реверс-инжинирится за пределами того, что
устройство открыто отдаёт.

Обложки следуют собственному artwork-конвейеру устройства: каждая
обложка получает токен, а файл кладётся в
`iTunes_Control/iTunes/Artwork/Originals/<xx>/<sha1-токена>` — схема
снята с живого устройства и сверена с запросами самой системы.

## Требования

- Linux с GNOME-совместимым окружением (GTK4 ≥ 4.10, libadwaita ≥ 1.4)
- libimobiledevice, usbmuxd
- TagLib ≥ 1.12
- Устройство Apple под управлением iOS; при первом подключении
  подтвердите на устройстве запрос **«Доверять этому компьютеру?»**

## Установка

### Из .deb-пакета (Debian/Ubuntu)

```bash
sudo apt install ./apple-devices_1.0.0-1_amd64.deb
```

### Из исходников

```bash
meson setup build --buildtype=release
meson compile -C build
sudo meson install -C build
```

Удаление: `sudo ninja -C build uninstall`.

## Замечания по использованию

- **Закройте приложение «Музыка» на устройстве перед импортом** — база
  медиатеки правится напрямую, и открытое приложение «Музыка» может её
  перезаписать.
- После импорта треки и обложки появляются в «Музыке» сразу; если
  приложение было открыто во время импорта — просто переоткройте его.
- Перед каждой записью базы создаётся автоматическая резервная копия —
  если что-то пойдёт не так, прежнее состояние лежит в
  `~/.local/share/apple-devices/backups/`.

## Сборка пакета

Debian-пакет собирается приложенным скриптом:

```bash
./scripts/build-deb.sh
```

Скрипт компилирует приложение, собирает установочное дерево, вычисляет
зависимости от библиотек через `dpkg-shlibdeps` и создаёт
`apple-devices_<версия>-1_<арх>.deb`.

## Ограничения и планы

- Плейлисты читаются с устройства; редактирование из приложения в планах
  (схема `container`/`container_item` на устройстве уже изучена).
- Индикатор синхронизации в статус-баре iOS отражает закрытый протокол
  Apple MobileSync и сознательно не входит в рамки проекта.
- Цветовой анализ обложек (цвета фона и текста, которые iOS использует
  в некоторых представлениях) аппроксимируется нейтральными значениями.

## Разработка с участием ИИ

Для полной прозрачности: код этого репозитория написан ИИ-ассистентом —
**GLM** (модель компании Z.ai) — в интерактивных сессиях совместно
с автором. Автор направлял работу, принимал продуктовые решения и
проверял каждую функцию на реальном iPhone по USB. Всё неочевидное здесь
(схема базы медиатеки, хеширование токенов обложек) не выдумано, а
снято и проверено на живом устройстве.
